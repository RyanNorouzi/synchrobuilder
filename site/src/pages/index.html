A Claude Code plugin · MIT · macOS, Windows, Linux

Multiplayer Claude Code for teams on any laptop.

No server, safe by design. Synchrobuilder keeps your project running on all three operating systems while Claude writes code, and lets several developers work in one repo at the same time, each Claude aware of what the others are doing. It uses the git remote you already have.

What it does

Run anywhere

Portability, kept honest by CI

  • Audit finds OS-specific assumptions: import casing, Unix-only scripts, hardcoded paths, line endings, Windows-illegal names, native binaries, one-OS READMEs.
  • Fix proposes each change as a diff and applies it only when you say so.
  • A guard re-audits every file Claude edits and tells it, in the same turn, if it just broke another OS.
  • A manifest, setup, doctor and a three-OS GitHub Actions workflow get a teammate from clone to passing health check.
Stay in sync

Presence over your git remote

  • Each developer publishes their own small state ref; nobody merges anything and nobody hosts anything.
  • Session start injects a short digest: who is active, claims that touch your area, messages for you, handoffs since you left.
  • Claims and collision warnings before an edit, at most once per file per 30 minutes, never blocking.
  • Notify, a minimal task board, and structured handoffs built from local session events.
Safe by design

Trust is earned by the code

  • Every hook exits cleanly with no output on any internal error and logs locally. Offline or slow, you keep coding.
  • Only handle, branch, a 140-character task summary, repo-relative paths, short messages and handoff notes ever leave your machine, after secret redaction.
  • Anything from another machine is wrapped as untrusted data that Claude is told not to follow as instructions.
  • Anything that changes your machine shows the plan first and asks before each step. No silent sudo.

What is real today

This site never claims more than a test or a recorded run in the repository proves.

The plugin is built. Both pillars work and 223 tests pass on macOS: the portability audit with twelve rules, the fixers, the guard hook, the setup manifest with init, setup, doctor and the CI generator, and the whole multiplayer path over a real git remote.

Proven by a test or a recorded run: two developers on one machine with one bare remote see each other's presence, get a collision warning from a claim, exchange a message and receive a handoff, with neither repository touched; a live Claude Code session quotes the guard's note back in the same turn it made the edit; a missing node never blocks a session; hooks cost 21 to 26 ms end to end here.

Not verified yet: anything on Windows or Linux, which the CI matrix covers on the first push; installing through a marketplace; the permission prompt and status line as the terminal renders them; and custom git refs on hosted providers. The full ledger is docs/VERIFICATION.md.
