Generated from docs/commands.md at build time, so this page and the plugin cannot drift. commands.

Inside Claude Code every command is /synchrobuilder:<name>. The Claude Code docs say it also accepts the bare short form, such as /audit, whenever no built-in command owns that name; /init, /doctor and /status are built-ins, so those three need the full form. We have not checked the short form in the command menu interactively, so it stays on the unverified list in docs/VERIFICATION.md. Outside Claude Code and in CI, the same commands run as npx synchrobuilder <name>.

Every command below is available in 0.1.0. The status pill comes from docs/commands.md, which the plugin itself ships, so this page cannot drift from the reference.
