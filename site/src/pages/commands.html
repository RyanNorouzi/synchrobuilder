Commands

Generated from docs/commands.md at build time, so this page and the plugin cannot drift. commands.

Inside Claude Code every command is /synchrobuilder:<name>. Claude Code also accepts the bare short form, such as /audit, whenever no built-in command owns that name; /init, /doctor and /status are built-ins, so those three need the full form. Typing /audit highlights /synchrobuilder:audit in the menu on Claude Code 2.1.236 and later. Outside Claude Code and in CI, the same commands run as npx synchrobuilder <name>.

Every command below is planned: the interface is agreed, the code is not written. The status pill changes to available when a command ships and its tests pass.
